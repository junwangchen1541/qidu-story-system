# 长期决策

## 2026-10-24：一个仓库、两个应用

网页端和微信小程序共享剧情数据与状态机，分别维护平台渲染层。理由是两端只有平台差异，路线条件、私信、变量和结局判定应保持单一来源。

## 2026-10-24：原作资源不进入公开仓库

APK、解包文本、完整剧情、CG、立绘、音乐和视频继续保留在本地私有素材库。GitHub 只同步自写代码、占位路线、schema、manifest、工具和文档。

## 2026-10-24：暂不引入跨端 UI 框架

先使用轻量共享 JavaScript 核心，网页和小程序各自渲染。等共享数据模型稳定后，再评估是否需要 Taro 或 uni-app。
