# 素材与发布管理

## 项目内容

本项目以《永远的7日之都》为创作背景，按独立互动叙事游戏进行开发和维护。项目包含共用剧情系统、网页端、微信小程序端、原创内容与平台构建流程。

代码和文档采用 MIT License。角色、剧情、美术、音乐及其他游戏素材分别按其来源和许可条件管理；代码许可不替代素材许可。

## 资产状态

每项游戏资产进入项目时记录来源、权利状态、署名要求、适用平台、校验结果和存储位置。按以下状态推进：

- `development`：制作与校对中的素材，仅供开发环境使用。
- `reviewed`：来源与授权信息已核实，进入内容验收。
- `release-ready`：已通过目标平台适配与发布审核，可进入对应游戏构建。

`manifest/` 记录公开资产条目和占位资源；完整开发素材按项目的本地资产目录管理。账号、签名文件和平台后台凭据使用本地或 CI 密钥配置，不进入内容仓库。

## 构建与发布

每个公开发行版本使用 `npm run build:release` 生成 Web 与微信小程序构建包及 ZIP，输出位于 `dist/releases/`。工具要求源码已提交，校验发行资产状态，并按版本与提交号保存归档；相同输入重复构建会复用相同归档。工具记录：

- 版本号、Git 提交和构建时间。
- 平台、最低运行环境及构建配置。
- 资产清单版本、授权状态和署名信息。
- 自动化检查结果、关键流程验收和已知兼容性问题。
- 构建包校验值、更新说明与存档迁移要求。

发布前按平台检查启动、主线流程、选项分支、存档读写、音视频播放和资源加载。网页、微信小程序及后续平台分别记录验收结果；通过验收的构建包与版本说明一同归档。

## 内容展示与来源

当前公开演示使用通用占位背景、角色剪影和示例剧情，展示地图、事件、对白、选项及存档流程。正式游戏构建按 `release-ready` 状态选取素材，并附带对应平台的署名和版本信息。

资产条目保留来源路径、来源说明、文件 hash、校验状态和平台范围，便于内容更新时追踪变更及重建发行包。

## 资产审核与更正

收到素材来源或授权范围的更正信息后，按以下流程处理：

1. 登记资产标识、来源和涉及的平台构建。
2. 暂停相关资产进入新的发行构建，并核对来源记录。
3. 更新资产状态、内容包和署名信息。
4. 对受影响的平台版本执行回归并发布修正版说明。
