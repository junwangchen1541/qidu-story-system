# 版权与公开边界

## 项目定位

本项目是非商业同人研究项目，目标是保存、研究和复现一种剧情交互范式，而不是分发原作内容。

公开仓库应尽量只包含“方法、结构、工具、占位演示”，避免包含原作资源本体。

## 可以公开的内容

- 自写代码。
- 自写文档。
- 自写或占位的示例剧情。
- 剧情系统结构设计，例如地点、事件、选项、私信、演出效果、结局条件。
- 资源清单字段，例如资源名、用途、来源说明、hash、是否已校验。
- 本地构建工具，前提是工具本身不内置原作资源。

## 不应公开的内容

- 原作 APK、安装包、补丁包。
- 解包后的原始客户端资源。
- 原作完整剧情文本或大段连续剧情文本。
- 原作 CG、立绘、音乐、视频、UI 图片。
- OCR 原始视频帧。
- 私有服务器账号、密码、部署记录。

## 可以在私有环境保留的内容

个人研究用途下，可以在本地私有目录保存：

- 本地安装包备份。
- 私有素材库。
- 解包后的文本候选。
- OCR 中间结果。
- 完整私人体验版 demo。

这些内容应通过 `.gitignore` 排除，不进入公开仓库。

## 对外展示建议

公开演示优先使用：

- 占位背景。
- 占位角色剪影。
- 少量自写示例文本。
- 不包含原作文本的流程样例。

如果需要展示原作相关工作进度，建议只展示结构性成果，例如“某路线已完成节点映射”，不要公开原文和图片。

## 权利方请求处理

如果原权利方或相关代理提出移除请求，维护者应优先处理：

1. 先临时下架争议文件或页面。
2. 记录涉及路径和原因。
3. 移除原作资源或改为占位内容。
4. 在 issue 或公告中说明处理结果。
