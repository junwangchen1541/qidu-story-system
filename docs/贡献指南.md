# 贡献指南

## 可接受贡献

- 改进移动端、桌面端体验。
- 改进地图选择、对话框、私信系统、黑屏白字、白屏、震动等演出。
- 增加剧情数据 schema 校验。
- 补充资源 manifest 字段。
- 编写文本整理流程、校验流程、OCR 后处理流程。
- 提交 bug 报告和体验反馈。

## 素材贡献要求

素材贡献附带来源、权利状态、署名要求、目标平台和资源校验信息，由维护者完成内容验收后纳入对应构建。平台账号和签名凭据通过本机配置或 CI 密钥管理。

## Issue 模板建议

反馈体验问题时，请提供：

- 设备：手机 / 平板 / 桌面。
- 浏览器：Chrome / Safari / Edge / Firefox。
- 屏幕方向：竖屏 / 横屏。
- 问题位置：地图 / 对话 / 私信 / 结局 / 其他。
- 复现步骤。

## 资源缺口记录方式

资源索引记录资产状态和来源信息，发行构建按平台选择已验收的资源：

```text
路线：第一章
节点：高校学园入口
资源类型：背景 / 立绘 / CG / 音频 / 文本
状态：缺失 / 待校验 / 已定位
来源说明：本地私有资源或公开资料名称
备注：记录资源缺口或验收信息
```
