# 七都式剧情系统复现计划 0.3.0

游戏首个正式编号版本，建立网页与微信小程序共用的事件驱动剧情系统和发行维护流程。

## 本版内容

- 两端共用剧情状态机，支持地图事件、对白、选项、私信解锁、存档和结局条件。
- 网页新增自动演出能力：定时推进、选项等待、暂停恢复、本地视频片段衔接。
- 提供公开占位路线、数据校验、单元测试、桌面和移动尺寸的浏览器测试。
- 补充持续集成、变更日志、贡献说明和发布流程。
- 建立游戏版本编号、平台验收和存档兼容检查流程。

## 使用方法

需要 Node.js 20 或更高版本。下载源码后运行 `npm ci` 和 `npm run build`，再打开 `apps/web/index.html`。开发与测试步骤见 README。

## 版本状态

- 当前版本处于开发阶段，剧情路线格式与界面表现仍在迭代。
- 网页端支持自动演出；微信端的实机适配仍在开发中。
- 本版交付项目源码和网页演示；网页使用通用占位资源展示游戏流程。
- 微信小程序构建包将在真机验收后随对应版本发布。

## 验证

发布验证包括构建、7 项 Node 测试、公开路线校验，以及桌面和移动尺寸的浏览器回归。GitHub CI 覆盖公开路线；微信真机验收列入后续平台测试。
