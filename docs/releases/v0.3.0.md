# Qidu Narrative System 0.3.0

七都叙事系统首个正式编号的公开版本。当前为 1.0 之前的研究原型，面向网页和微信小程序共用的事件驱动叙事。

## 本版内容

- 两端共用剧情状态机，支持地图事件、对白、选项、私信解锁、存档和结局条件。
- 网页新增自动演出能力：定时推进、选项等待、暂停恢复、本地视频片段衔接。
- 提供公开占位路线、数据校验、单元测试、桌面和移动尺寸的浏览器测试。
- 补充持续集成、变更日志、贡献说明和发布流程。
- 项目正式名称统一为 Qidu Narrative System，仓库名改为 qidu-narrative-system。

## 使用方法

需要 Node.js 20 或更高版本。下载源码后运行 `npm ci` 和 `npm run build`，再打开 `apps/web/index.html`。开发与测试步骤见 README。

## 已知限制

- 这是早期研究原型；1.0 之前的数据格式和界面行为可能调整。
- 公开演示使用占位剧情与图形，不包含原作剧情、OCR 长文本、CG、音视频或 APK。
- 自动演出当前在网页实现；本版不宣称微信模拟器或手机实机验证通过。
- 私有素材构建只在本地使用，不作为公开下载内容。

## 验证

发布前执行构建、7 项 Node 测试、公开路线校验，以及桌面和移动尺寸的浏览器回归。GitHub CI 只运行公开占位路线，跳过依赖本地私有素材的测试。
