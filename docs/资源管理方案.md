# 资源管理方案

## 双层仓库策略

公开仓库：

- 保存代码、schema、工具、manifest、文档。
- 不保存原作资源。

私有素材库：

- 保存 APK、解包数据、CG、立绘、音乐、OCR 结果、完整私人 demo。
- 不推送到 GitHub/Gitee。

## 推荐本地目录

```text
qidu-story-system-public/
  demo_public/
  docs/
  schema/
  tools/
  manifest/

qidu-private-assets/
  apk/
  extracted_text/
  cg/
  portrait/
  audio/
  ocr/
  build_private/
```

## manifest 管理

公开仓库可以保留资源清单，但不保留资源文件：

```csv
id,type,title,private_path,public_placeholder,status,source_note,sha256
bg_awake,bg,醒来,private/cg/001.jpg,demo_public/placeholders/bg_awake,private_only,本地私有资源,
```

`sha256` 可以用于个人本地校验，但不要把可下载链接写入公开仓库。

## 构建原则

- `demo_public` 永远可公开运行。
- `apps/web` 与 `apps/wechat` 只负责平台渲染，共享 `packages/story-core` 和 `data/routes`。
- 路线条件、变量效果、私信读取、存档序列化等行为只在 `packages/story-core` 维护，平台端不复制状态机。
- `build_private` 只在本地生成完整体验版。
- 本地构建脚本读取私有素材目录，但输出目录必须被 `.gitignore` 排除。
