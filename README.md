# 七都式剧情系统复现计划

这是一个非商业、同人性质的剧情系统研究与复现项目。项目目标不是重新发布《永远的7日之都》，而是研究并复现其“有限地点内通过事件选择推进叙事”的交互范式：地图选择、视觉小说式对白、私信触发、黑屏白字、白屏、震动、分支与结局。

## 当前公开范围

本仓库只公开可协作的工程部分：

- 剧情系统前端 demo，占位素材版。
- 剧情节点、地点、私信、演出效果的数据结构。
- 资源清单模板。
- 文本整理、资源管理、贡献边界文档。

本仓库不包含：

- 原作 APK、解包资源或客户端数据表。
- 原作完整剧情文本。
- 原作 CG、立绘、音乐、视频或 UI 资源。
- 可直接替代原游戏体验的完整资源包。

## 在线体验

公开仓库中的 `demo_public/` 使用占位文本与 CSS 背景，只用于展示系统交互方式。私人完整资料库和原作资源不会进入公开仓库。

## 开发方式

直接打开：

```bash
demo_public/index.html
```

或用任意静态服务器：

```bash
python -m http.server 8080 -d demo_public
```

## 仓库结构

```text
demo_public/        # 占位素材版交互 demo
docs/               # 版权边界、贡献规范、整理方法
schema/             # 剧情数据结构
tools/              # 本地工具说明与占位脚本
manifest/           # 资源清单模板，不含资源本体
```

## 贡献原则

- 可以贡献系统代码、交互设计、演出实现、结构化整理方法。
- 可以贡献资源索引、来源说明、hash、缺口标记。
- 不要提交原作 CG、立绘、音乐、视频、APK 或完整剧情文本。
- 不要提交任何账号、密码、服务器信息或私有部署记录。
